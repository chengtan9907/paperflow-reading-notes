# Unbiased Top-$k$ Estimation for On-Policy Distillation

> ★★★★☆ 推荐阅读 · 模型 openai-compatible/deepseek-v4-flash

🏷 关键词：on-policy distillation · reverse kl divergence · top-k estimation · unbiased gradient estimation

## 一句话总结

TT-OPD 在 top-k 选择集之外额外引入学生 rollout 中采样 token 的尾部校正项，使反向 KL 散度梯度的估计在期望上无偏（等价于全词表估计），同时保持接近 TK-OPD 的计算成本，实验显示其在数学推理与代码生成任务上稳定优于现有 OPD 变体。

## 摘要

> On-policy distillation (OPD) is becoming an important component of large language model (LLM) post-training for transferring the reasoning capability of a strong teacher LLM to a weaker student LLM. OPD trains the student by minimizing the reverse KL divergence between the teacher and the student via rollouts generated by the student's policy. However, estimating the gradient of the reverse KL divergence in OPD remains a challenge. Using only the sampled token from the student-generated rollout is computationally cheap but provides limited distributional supervision, which will degrade accuracy. In addition, using the full vocabulary provides complete distributional supervision but is computationally expensive. Therefore, recent works propose Top-$k$ OPD (TK-OPD) that use selected top-$k$ tokens, which provides richer distributional supervision than sampled-token estimation at substantially lower computational cost than full-vocabulary estimation. Unfortunately, using only the selected top-$k$ tokens induces bias, leading to accuracy degradation, as the probability mass outside the selected top-$k$ tokens is discarded. To address the bias of TK-OPD, we propose Tail-Corrected Top-$k$ On-Policy Distillation (TT-OPD). It preserves the advantages of TK-OPD, including rich distributional supervision and low computational cost, while providing an unbiased estimator of the gradient of the reverse KL divergence. The key insight of TT-OPD is to use not only the selected top-$k$ tokens, but also the sampled token from the student-generated rollout, thereby recovering the discarded probability mass in expectation, avoiding the bias. Experimental results demonstrate that TT-OPD significantly outperforms other tested OPD variants.

Q1: 这篇论文试图解决什么问题？

这篇论文试图解决 on-policy distillation（OPD）中反向 KL 散度梯度估计的偏差-方差-成本三难问题。背景是 LLM 后训练阶段需要把强教师模型的推理能力迁移给弱学生模型，OPD 通过学生自身策略产生的 rollout 来最小化学生与教师之间的反向 KL 散度，相比 off-policy distillation 能缓解暴露偏差（exposure bias），并且已经在多个前沿 LLM 的后训练流程中被采用。

具体矛盾体现在梯度估计的三个候选方案上：
1. ST-OPD（Sampled-Token OPD）：只使用学生 rollout 中实际采样到的那个 token 构造梯度估计，计算代价低，但每个位置只提供一个 token 的监督信号，对教师分布的形状信息利用极少，分布监督弱，导致训练精度下降。
2. FV-OPD（Full-Vocabulary OPD）：对完整词表上教师与学生分布的差异逐 token 计算梯度贡献，分布监督完整，但现代 LLM 词表规模巨大，逐词表前向/梯度计算代价高昂，难以实际部署。
3. TK-OPD（Top-k OPD）：只选取概率最高的 k 个 token 计算精确梯度贡献，折中方案，保留了大部分分布监督且成本可控，但问题是它把 top-k 之外的“尾部”概率质量直接丢弃，这些被丢弃的质量没有被任何方式补偿，导致梯度估计产生系统性偏置，进而造成蒸馏精度退化。

论文的核心洞察在于：TK-OPD 丢弃的尾部概率质量并非不可恢复——学生 rollout 中采样到的 token 正是按该分布抽取的，它天然携带了尾部概率质量的信息。因此无需在全词表上计算，只需在 top-k 项之外再附加一个采样 token 的校正项，就可以在期望上补回被丢弃的概率质量，实现无偏估计。需要强调的是，“无偏”在这里是指估计器在期望意义上等于全词表（FV）梯度；而单个位置采样一个 token 的方差仍然存在，这是论文在高效性上付出的代价。该问题属于 LLM 蒸馏中估计器设计的研究范式竞争：在“便宜的弱监督”与“昂贵的完整监督”之间寻找统计上可证明、计算上可行的中间点，并用期望无偏性取代近似无偏性作为方法成立的理论保证。

Q2: 有哪些相关研究？

1. 蒸馏范式之争：off-policy vs on-policy。传统蒸馏用教师生成的 rollout 训练学生（off-policy），而 OPD（Agarwal et al. 2024；Kevin and Lab 2025）改用学生自己的策略生成 rollout，使学生在真实访问的状态上精炼行为（Li et al. 2026 等），缓解 off-policy 蒸馏中因状态分布不匹配带来的暴露偏差，该偏差被认为阻碍推理能力从强教师向弱学生的迁移（Song and Zheng 2026；Hou et al. 2026）。

2. OPD 在前沿 LLM 后训练中的普及。论文引言列举了大量把 OPD 用于 frontier-level LLM 后训练的工作（Yang et al. 2025；Zeng et al. 2026；Xu et al. 2026；Xiao et al. 2026 等），说明该问题是当前 LLM 训练实务而非纯学术问题，估计器改进有直接落地价值。

3. 推理能力迁移研究。Gu et al. 2024、Xu et al. 2025、Fu et al. 2026、Oh et al. 2026、Zheng et al. 2026、Zhu et al. 2026、Zhao et al. 2026、Shenfeld et al. 2026 等被引作推理能力迁移的代表工作，构成 OPD 的应用动机。

4. Top-k 蒸馏估计。与本文最直接相关的是 TK-OPD 及其变体（Hüb0tter et al. 2026；Li et al. 2026），它们用 top-k token 提供比采样单 token 更丰富的分布监督；本文正是在此基础上指出其偏置问题并给出修正。

5. 蒸馏领域更广的文献。参考文献残片中出现了 DDK: Distilling Domain Knowledge for Efficient Large Language Models（Zhang et al. 2024）等蒸馏工作，但检索证据无法确认其在正文中的具体引用语境，只能归入蒸馏相关背景。

Q3: 论文如何解决这个问题？

TT-OPD 的解决方案分三层：形式化 OPD 框架、定义尾部校正估计器、证明其无偏性。

1. 形式化框架：假设学生策略 p_θ 在每个时间步 t 定义词表 V 上的分布，OPD 目标是最小化教师分布与 p_θ 的反向 KL 散度。FV-OPD 的梯度 ∇θ L_FV^t(θ) 需要对词表中每个 token v 的 p_θ(v) 贡献求和，这是无偏但昂贵的项；ST-OPD 只保留采样 token y_t 的贡献，廉价但有偏（这里的有偏指相对 FV 梯度，监督信息不足导致精度劣化；严格说是估计器方差与信息量问题，论文用“提供有限分布监督”表述）。

2. TT-OPD 估计器结构：在每个位置 t，选定集合 S_k^t（概率最高的 k 个 token，或按其他规则选取的 k 个 token），对集合内每个 token 精确计算其梯度贡献项；同时额外纳入学生 rollout 中实际采样到的 token y_t。依据 retrieved_evidence 的描述，二者分工明确——“selected set S_k^t 指明哪些 token 级梯度贡献被精确计算，sampled token y_t 提供尾部校正”。即 L_TT^t 由 top-k 精确项加上采样 token 的校正项组成，校正项在形式上是把被丢弃的尾部概率质量“按期望”接回来。

3. 无偏性定理（Theorem 4.1）：论文证明 E_{y_t∼p_t}[∇θ L_TT^t(θ)] = ∇θ L_FV^t(θ)，即 TT-OPD 的梯度估计在期望上等于全词表梯度，因而是无偏的。证明的关键等式来自概率归一化性质：
 Σ_{v∈V} ∇θ p_θ(v) = ∇θ Σ_{v∈V} p_θ(v) = ∇θ 1 = 0。
 这一恒等式意味着尾部概率质量的梯度贡献可以借助具有 tail 分布的单个采样 token 在期望意义上恢复，无需枚举整个词表。

4. 性质继承与兼容性：retrieved_evidence 显示论文明确说明 TT-OPD“继承了 ST-OPD 与 FV-OPD 梯度估计的无偏性”，并声称其设计“兼容其他 OPD 改进”——即 S_k^t 的选择规则、top-k 精确项之外的附加校正项可以与其他对 OPD 目标或 rollout 的改进叠加。计算成本上，TT-OPD 相对 TK-OPD 只多了一个采样 token 的前向/梯度项，增加有限，而相对 FV-OPD 节省了整个尾部词表的计算。

需要标注的缺口：检索证据没有给出 L_TT 的具体解析形式（如各项的系数、是否对采样 token 做重要性加权），上述描述基于证据片段的方向性归纳，公式细节需查原文 Section 4 确认。

Q6: 有什么可以进一步探索的点？

基于论文的问题设定与证据边界，可以列出以下可进一步探索的方向，其中前两条最贴合论文内部逻辑；

1. 尾部校正项的设计空间：当前方案固定用单个采样 token 做尾部校正，可探索多个采样 token、重要性加权、或按尾部概率质量动态决定采样个数的变体，在方差与成本之间再作权衡；理论上可分析校正项的方差上界并与其他低方差估计技术（如控制变量）结合。

3. 与其他 OPD 改进的组合验证：论文声称 TT-OPD 兼容其他 OPD 改进，但检索证据未见具体组合实验；把尾部校正与 rollout 长度惩罚、置信度过滤、正则化项等实务技巧组合，检验收益是否叠加。

4. 理论边界的深化：论文只证明期望无偏性（一阶矩），方差分析、收敛速度、与 Adam 等优化器交互下的随机梯度行为、尾部采样 token 与 top-k 项的相关性结构都值得刻画；也可用浓度不等式给出蒸馏损失估计的 PAC 界。

5. 扩展到更大规模与前沿模型：实验学生规模有限，可在更大参数规模、多语言/多模态教师、以及 RLHF/GRPO 全流程后训练中验证；数学与代码之外的长文本推理、工具调用（agent）场景下尾部概率质量的行为可能不同。

6. 与 agent/科学应用结合：用户画像关注 agent 与 AI-for-science；OPD 可在 agent 轨迹蒸馏场景中迁移推理策略，TT-OPD 的无偏性对轨迹级长序列累积误差更友好（最多 32,768 token 的 rollout 设定暗示长序列场景已在论文射程内），这属于跨领域联系的推测，需要新实验验证。

Q7: 总结一下论文的主要内容

论文的研究主线是 LLM 后训练中 on-policy distillation（OPD）的梯度估计方法，其论证-技术-实验三条主线如下。

论证主线：OPD 已成为前沿 LLM 后训练的重要组件，因为它用学生自身 rollout 最小化与教师的反向 KL 散度，能缓解 off-policy 蒸馏的暴露偏差并有效迁移推理能力。但反向 KL 梯度的估计陷入三难：只采一个 token（ST-OPD）便宜却监督弱；全词表（FV-OPD）监督完整却成本不可承受；中间的 top-k（TK-OPD）虽然兼顾监督与成本，却因丢弃 top-k 之外的概率质量而引入偏置，损失精度。论文的判断是：这个偏置不是必须接受的代价，因为学生 rollout 的采样 token 恰好按被丢弃的尾部分布抽取，可以在期望上把质量“找回来”。这一论证把问题从“选择监督的丰富度”重构为“在有偏的稀疏监督上做统计校正”，从而把无偏性重新放回低成本估计器的可达范围。

技术主线：论文先形式化 OPD 框架，再定义 TT-OPD 估计器：对选定的 S_k^t（top-k 集合）精确计算 token 级梯度贡献，同时把学生 rollout 采样到的 token y_t 作为尾部校正项纳入；然后证明定理 4.1，即 E_{y_t∼p_t}[∇θ L_TT^t(θ)] = ∇θ L_FV^t(θ)，无偏性证明的关键是词表概率归一化恒等式 Σ_v ∇θ p_θ(v) = ∇θ 1 = 0。由此 TT-OPD 同时继承 ST-OPD 与 FV-OPD 的无偏性，保留 TK-OPD 的低成本与丰富监督，并宣称兼容其他 OPD 改进。

实验主线：在数学推理基准（AIME24/25/26、AMC、MATH、Minerva、Olympiad 及平均分）与代码生成任务（教师为 Qwen3-8B-Base-GRPO-Code）上验证；生成配置为 temperature 0.6、top-p 0.95、top-k 20、最大长度 32,768 tokens。结果以 Finding 形式总结：Finding 1 是 TT-OPD 在不同学生规模上一致优于 ST-OPD 与 TK-OPD；Finding 3 是训练时间相对 TK-OPD 最多增加约 6%。在代码生成任务上对 k∈{8,16,32,64} 做了消融。整体结论是：TT-OPD 以约 6% 的额外训练时间换得无偏性，并在多个任务与规模上稳定提升蒸馏精度。

需要提醒的是，检索证据主要来自 Introduction 与附录残片，Finding 2 的内容、消融的具体数值趋势、学生模型细节均未落入证据范围；本总结对已见证据忠实复述，对缺环作了明确标注而非补全。
