# Probability is Not Enough: Exploring and Counting Divergent Tokens for Reasoning Uncertainty Quantification in LLMs

> ★★★★☆ 推荐阅读 · 模型 openai-compatible/deepseek-v4-flash

🏷 关键词：uncertainty quantification · chain-of-thought reasoning · divergent tokens · jensen-shannon divergence

## 一句话总结

本文提出 Divergent Token Confidence (DTC) 框架，通过统计生成模型与辅助模型在同一推理轨迹上对下一个 token 预测产生强烈分歧（基于 Jensen-Shannon 散度）的 token 数量，来量化 LLM 推理答案的置信度与校准度，无需训练、不改变生成过程，并同时支持白盒与黑盒评估；在多个数学基准和多个模型家族上显著降低了期望校准误差。

## 摘要

> 论文关注大语言模型（LLM）在思维链（Chain-of-Thought, CoT）推理中的置信度评估与校准问题。现有方法大多基于选中的关键 token 的概率来估计模型对答案的置信度，但其底层机制并不清楚。作者的预研究（pilot study）发现，将选中 token 的概率替换为粗略替代物也能改善校准，这促使他们进一步探索更有效的置信度信号。为此，论文提出了 DTC 框架：通过 Jensen-Shannon 散度比较两个模型沿同一推理轨迹的 next-token 分布，识别出模型间强烈分歧的 token，并对这些分歧 token 计数。作者发现该计数值与答案准确率几乎负相关，因此可以作为简单有效的不确定性量化信号。DTC 可用辅助模型实现白盒和黑盒两种评估，无需显式训练，也不影响生成过程。在多个模型家族和六个数学基准上的实验表明，相比基于概率的和基于口头化（verbalized）的基线方法，DTC 能显著改善校准。白盒设置下，仅计数估计器平均期望校准误差达 13.0%，而标准全序列置信度方法为 32.7%–42.4%；黑盒设置下，在 DeepSeek-V3.2 上平均 ECE 从 32.1%–40.2% 降至 13.7%–16.3%。代码已开源。

Q1: 这篇论文试图解决什么问题？

这篇论文试图解决的核心问题是：如何准确且可信地量化 LLM 在 CoT 推理过程中的不确定性/置信度，从而判断一条推理轨迹是否可靠。具体而言，论文针对以下子问题展开：

1. **推理轨迹置信度与答案正确性的错配**：一条能推出正确答案的轨迹，其中间步骤可能不可靠；反之，一条中间步骤看似合理但最终答案错误的轨迹也可能存在。单纯依赖最终答案或整条轨迹的概率不能反映推理过程的真实可靠度。在安全关键场景中，这种错配会放大模型不可靠性，因此需要更好的置信度信号。

2. **现有概率方法的机制不明**：当前主流方法（如基于选中 token 的概率）虽然在一定程度上有效，但在 UQAC 的积分形式中，最终分数同时依赖于 token 概率值和被选 token 集合的大小 |S|，论文无法确定校准收益到底来自概率本身，还是来自被选 token 的数量。作者通过预实验发现，即使把选中 token 的概率替换为粗糙替代值，校准也能改善，说明“选择哪些 token”也许比“这些 token 的概率是多少”更重要——这动摇了概率信号作为唯一依据的合理性。

3. **缺乏训练无关、生成无关且可迁移的置信度信号**：许多不确定性估计方法需要额外训练过程奖励模型（PRM）或改变解码方式（如采样多次、自一致性），代价高且不适用于所有场景。论文希望找到一种简单、无需训练、不干预生成、同时支持白盒（可访问 logits）和黑盒（只能访问文本/概率输出）的置信度信号。

4. **黑白盒统一评估**：现实部署中，很多模型只提供 API 而不开放 logits，因此置信度估计方法应能在仅有外部可观测信息（如模型口头化置信度、辅助模型分布）时也能工作。论文要求方法同时适配这两种设置。

5. **校准与辨别力的平衡**：多数方法只优化期望校准误差（ECE），但可能损失排序能力（AUROC）。DTC 需要在降低 ECE 的同时保持甚至改善对正确/错误答案的辨别能力。

论文的核心洞察是：与其关注“模型对某个 token 有多确信”，不如关注“另一个模型在同一个推理位置上是否与它意见一致”。统计分歧 token 的数量，可以捕捉推理轨迹中潜在的脆弱点，而这些脆弱点与最终的推理失败高度相关。这样就把置信度估计从“概率值”转向“结构计数”，从而绕开概率本身的语义模糊性。

Q2: 有哪些相关研究？

论文涉及的相关研究可以归为以下几类：

1. **基于序列/全轨迹概率的置信度估计**：这是最传统的一类，包括长度归一化序列似然（CNSL）、平均 token 概率（Cmean）、长度归一化预测熵置信度（Entropy Confidence）等。这些方法直接把整条 CoT 轨迹中所有 token 概率的某种聚合作为置信度，但容易受路径长度、冗余 token 和 token 概率尺度影响。

2. **对全序列置信度的改进**：例如 BaseCal（用配对的基础模型对响应 token 概率求平均进行校准）、UQACattn（基于注意力选择重要 token，再乘积这些 token 概率）以及论文提出的变体 UQACmean（把选中 token 的概率替换为 Cmean 再相乘）。UQAC 系列属于 token 选择方法：先挑选关键 token，再在选中的 token 子集上定义分数 \(\text{UQAC}_{attn} = \prod_{t\in S} p_t\)，其中 S 是选中集合。论文指出该分数同时依赖概率值和 |S|，因此无法分离“概率”和“集合大小”各自的贡献。

3. **口头化置信度（Verbalized Confidence）**：让模型直接用自己的话语输出对答案的信心分数。论文中使用了三种 verbalized 估计方法（Verb. Conf、Verb. TopK、Verb. PD），这些方法不需要访问 logits，但往往存在过度自信或表述不稳定等问题，且会显著降低默认 CoT 的准确率（论文在 DeepSeek-V3.2 上观察到该方法将平均准确率从 57.5 降到 44.9–51.5）。

4. **过程奖励模型（PRM）**：对推理过程中的每一步进行评估，通常需要额外训练。论文在白盒表格中观察到 PRM 并没有进入最好或第二好的标记，而 DTC 的简单计数在多个指标上超过了它。

5. **基于自洽性或采样的一致性方法**：这类方法通过多次采样解码并比较答案一致性，但大多需要改变生成过程、增加推理成本，因此论文没有将其列为主要基线。

6. **更广义的模型不确定性量化**：传统上还有基于熵、互信息、距离度量和集成方法等，但多数需要 logits 或多次前向。论文强调的是在单次生成轨迹上、无需训练和额外解码的轻量信号。

论文的独特定位是：不依赖概率绝对值，而是利用“两个模型对同一位置预测的分歧程度”来构造置信度。这与集成分歧度量有相似之处，但论文将其限制在同一推理轨迹的逐 token 比较上，并且允许使用异构辅助模型（甚至更小的模型）来提供“第二意见”。

Q3: 论文如何解决这个问题？

论文提出的 DTC（Divergent Token Confidence）框架由三个基本部分组成：

1. **分歧 token 的定义**：给定一个生成模型 G（generator）对输入问题产生的完整 CoT 轨迹，记轨迹为 token 序列 \(t_1, t_2, \ldots, t_n\)。每一步，G 的 next-token 分布为 \(P_G(\cdot \mid t_{<k})\)，辅助模型 A 在同一前文条件下得到分布 \(P_A(\cdot \mid t_{<k})\)。论文用 Jensen-Shannon 散度（JSD）来衡量两个分布的距离：\(JSD_k = \mathrm{JSD}(P_G(\cdot \mid t_{<k})\,||\,P_A(\cdot \mid t_{<k}))\)。若 \(JSD_k > \theta\)（θ 是预设阈值），则第 k 个 token 被标记为“分歧 token”（divergent token）。统计整条轨迹中分歧 token 的数量，记为 \(N_{\mathrm{div}}\)。

2. **两种置信度估计方式**：
 - **DTClin**：直接以计数作为置信度。由于计数与准确率几乎负相关，通常用 \(1 - \mathrm{normalize}(N_{\mathrm{div}})\) 或排序后的负计数作为置信度分数。论文在表 1 中显示 DTClin 在 ECE 上大幅优于所有基线。
 - **DTCprod**：用计数对轨迹的平均 token 概率进行重校准。更具体地，它不是在概率空间上做乘积，而是以“计数越大，置信度越低”的方式对轨迹的 Cmean 进行修正，从而生成更平滑的置信度分数。DTCprod 在需要把分数解释成概率时会比 DTClin 更自然。

3. **白盒与黑盒评估统一**：
 - 白盒设置：生成器 G 的 logits 和辅助模型 A 的 logits 都可用，可以直接计算每一步的 JSD。
 - 黑盒设置：无法访问生成器的 logits。论文使用一个辅助模型 A（例如 DeepSeek-V3.2 或 Qwen 系列）作为代理，对该轨迹重新解码，或者利用 A 在同样前文上的 next-token 分布来与某种“参考分布”做比较。具体而言，论文在黑盒中使用了三种 verbalized 估计器，并将 DTC 应用于它们：即先用 Verbalized 方法得到一个分数，再用分歧计数量对该分数进行重校准（表中的 “w/ DTC”）。

4. **为什么计数有效**：论文提出了一种解释——当两个模型对同一个推理位置的下一步预测产生明显分歧时，说明该位置可能存在歧义、知识冲突或推理脆弱性。这样的位置越多，整条轨迹倾向于包含更多错误决策，导致最终答案错误的概率更高。计数将这种“结构脆弱性”直接量化为一个标量，避免了概率值在不同模型、不同上下文中的尺度漂移。

5. **实际操作细节**：
 - 阈值 θ 需要设定。论文在图 4 中展示了 θ 的敏感性分析，在 θ 每 0.05 步长搜索下，最优 θ 随辅助模型大小变化：例如 1.5B 辅助模型可能选 0.40–0.50，32B 辅助模型可能选 0.25–0.55 等。
 - 辅助模型的大小可以远小于生成器（如用 1.5B 的 Qwen2.5 帮助 32B 的 Qwen3）。
 - 不使用任何显式训练，不改变生成过程，辅助模型只需在给定轨迹上做逐 token 前向，计算量可控。

Q4: 论文做了哪些实验？

论文的实验设计涵盖以下维度：

1. **白盒设置（White-box）**：
 - 数据集：MATH-500、AMC23、AIME24、AIME25 四个广泛使用的数学基准，覆盖不同难度（从通识数学到竞赛题）。
 - 模型：8 个模型，来自三个家族：Qwen2.5-{7,14,32}B-Instruct、Qwen3-{8,14,32}B、Gemma3-{12,27}B-IT。
 - 基线：标准全序列置信度（CNSL, Cmean, Entropy Confidence），改进版（BaseCal, UQACattn, 论文自变体 UQACmean），以及 Verbalized Conf/ TopK/ PD。
 - 指标：准确率（Acc↑）、期望校准误差（ECE↓）、AUROC（AUC↑）。
 - 关键对比表：表 1 给出各基线在四个数据集上的结果，并显示在基线上应用 DTClin 或 DTCprod 后的变化。

2. **黑盒设置（Black-box）**：
 - 实验针对 DeepSeek-V3.2，将三种 Verbalized 估计方法与 DTC 结合（w/ DTC）。论文报告了 DTC 在每种情况下均降低 ECE，且平均 ECE 从 32.1%–40.2% 降到 13.7%–16.3%。
 - 黑盒 DTC 采用“辅助模型做分歧检测”，且论文特别指出在这种设置中，Verbalized 方法往往会降低默认 CoT 准确率（从 57.5 降至 44.9–51.5），而 DTC 并不牺牲准确率。

3. **敏感性分析**：
 - 图 4 展示了 DTClin 对阈值 θ 和辅助模型大小的敏感性。在 AMC23 上使用单个辅助模型 Qwen2.5，θ 搜索步长 0.05，报告了最低 ECE 对应的 θ 值（从 1.5B 到 32B 辅助模型，最优 θ 在 0.25–0.55 之间）以及对应的 AUROC。
 - 结果表明 DTClin 对辅助模型大小和阈值并不特别敏感，在较宽范围内都能保持低 ECE。

4. **实验协议**：
 - 默认使用 CoT 生成完整轨迹。
 - 对 verbalized 方法使用提示模板（例如“Reason step-by-step to formulate your final answer. Your answer must be a mathematical value or short exact…”），以得到最终的数值答案。
 - 论文声称在所有白盒和黑盒设置中，DTC 都减少了 ECE，通常减少超过 20 个百分点，且 AUROC 变化很小或有时改善。

Q5: 发现了什么实验现象？

论文主要观察到的实验现象包括：

1. **计数与准确率的负相关**：这是 DTC 成立的直接证据。沿同一推理轨迹，两个模型强分歧的 token 数量越多，最终答案准确的可能性越低。这种负相关在多个模型和数据集上都稳定存在。

2. **替换概率也能改善校准**：UQAC pilot 发现，将选中 token 的概率替换为粗略替代（如 Cmean）后相乘，依然能改善校准。这个反直觉结果说明 UQAC 的大部分校准增益其实来自“选择多少 token”（集合大小），而不是这些 token 的具体概率值。作者由此推断概率值的精细程度并非关键，关键在于对轨迹中不确信位置的识别。

3. **DTClin 的 ECE 大幅优于概率基线**：在白盒中，仅使用计数的 DTClin 平均 ECE 为 13.0%，而标准全序列置信度（CNSL 等）为 32.7%–42.4%。即使在加上各种改进（BaseCal、UQACattn、UQACmean）以及 Verbalized 方法后，DTClin 仍然是最优或次优。

4. **AUROC 变化不大，有时改善**：尽管 ECE 显著下降，AUROC 并没有同步大幅上升，有时甚至略有下降。这表明 DTC 主要是“校准”了置信度分数，使分数和实际准确率之间的匹配更好，但并没有显著提高模型自身对正确/错误答案的内在判别力。不过论文提到在某些设置下 AUROC 也略有改善。

5. **黑盒中 Verbalized 方法会牺牲准确率，DTC 不会**：在 DeepSeek-V3.2 上，纯 Verbalized 方法在估计置信度的同时将平均准确率从 57.5 降到 44.9–51.5；当把 DTC 应用于 Verbalized 分数后，ECE 降到 13.7%–16.3%，同时避免了这种准确率惩罚。这可能是因为 DTC 不要求模型额外输出置信度，而是通过外部辅助模型进行观察。

6. **DTCprod 比 DTClin 稍弱但更易用**：DTCprod 在白盒和黑盒中的 ECE 低于 DTClin，但依然显著优于所有原始基线。例如在白盒中 DTCprod 的 ECE 在 24.6%–35.3% 之间（相对于原始基线的 32%–42%），比 DTClin 的 9.4%–19.2% 高，但好处是它输出的是概率尺度上的置信度，可直接用于阈值决策。

7. **对 θ 和辅助模型大小不敏感**：敏感性分析显示，在 θ=0.40–0.55 附近都能得到较低的 ECE，说明 DTC 不需要精确调参；辅助模型从 1.5B 到 32B 都能工作，较大辅助模型在低 ECE 上略优，但差异不大。

8. **PRM 并未领先**：在白盒最佳/次佳标记中，PRM 没有被标记为最佳或第二佳，进一步说明复杂的奖励模型不一定比简单计数更有利于校准。

9. **跨模型一致的趋势**：在 Qwen2.5、Qwen3、Gemma3 三个家族上，DTC 的校准改善均一致出现，说明该信号具有一定的模型无关性。

Q6: 有什么可以进一步探索的点？

论文的发现为后续研究打开了多个方向：

1. **分歧 token 语义分析**：论文只统计了数量，但尚未分析哪些类型的分歧（例如数字分歧、运算符分歧、逻辑连接词分歧）对最终错误更有指示性。未来可以按照 token 的语义类别对分歧进行加权，可能进一步提升 ECE 和 AUROC。

2. **动态阈值与自适应辅助模型**：目前 θ 是全局超参数。不同任务、不同模型可能应该使用不同的阈值。可以探索基于轨迹长度的自适应阈值，或通过小规模校准集自动选择 θ。另外辅助模型大小与生成器大小的匹配策略（例如什么比例的辅助模型最划算）值得系统研究。

3. **将 DTC 与过程奖励模型结合**：既然分歧计数与路径脆弱性相关，可以将计数作为特征输入到 PRM 或作为奖励 shaping 的一种信号，而不是完全放弃 PRM。这在数学推理的强化学习训练中有应用潜力。

4. **扩展到更多任务和模态**：论文聚焦于数学推理。DTC 也可以应用于代码生成、领域问答、多步规划等任务，甚至可能是多模态（视觉-语言推理）中衡量跨模型分歧。需要验证计数信号在其他领域是否依然保持负相关。

5. **理论解释**：目前“计数为什么与准确率负相关”的机制解释是直觉性的。未来可以从隐式知识冲突、模型容量差异、分布外 token 等角度建立理论模型，例如用信息论或误差传播来分析分歧点如何累积为最终错误。

6. **提高辨别力**：当前 DTC 主要改善校准而 AUROC 提升有限。可以探索将分歧计数与概率信号（例如分歧点的平均 JSD）结合，构造对正确和错误轨迹更有区分度的分数。

7. **无辅助模型的变体**：黑盒设置下若无法获得任何辅助模型，是否能用生成器自身的内部一致性（如不同解码层的分布差异）来代替“两个模型”的分歧？这可以把 DTC 扩展到完全封闭的 API。

8. **在线校准与主动学习**：由于 DTC 不需要训练，它非常适合在流式数据上在线监控模型的推理可靠性，也可以用于风险阈值设置、选择性回答和人类审查的触发条件。

9. **其他语言和推理风格**：当前主要测试英文数学题。DTC 在多语言、更长的非形式化推理（如科学推理、法律推理）上的表现还未探索。

10. **与自洽性方法的结合**：将多次采样的一致性分数与 DTC 计数合并成联合置信度，可能既保留校准又增强 AUROC。尽管这会增加推理成本，但对高安全场景是值得权衡的。

Q7: 总结一下论文的主要内容

论文围绕一个核心问题展开：如何对 LLM 的思维链推理轨迹进行可靠的置信度估计。作者首先发现现有基于关键 token 概率的方法（如 UQAC）在数学推理上虽然有用，但其校准增益的来源并不清晰。通过一个 pilot 实验，他们发现在 UQAC 中把选中 token 的概率替换为粗糙替代后校准依然改善，从而猜测真正起作用的是被选择的 token 集合，而不是集合中概率的精确值。这一观察直接挑战了“概率是置信度唯一基础”的普遍假设，并引出了一个更结构化的信号：两个模型在同一推理位置上的分歧。

基于此，论文正式提出 DTC 框架。DTC 的操作流程是：让一个辅助模型沿着生成器已经产生的轨迹重新解码，并在每一步用 Jensen-Shannon 散度比较两个模型的 next-token 分布。当某个位置的 JSD 超过阈值 θ，该 token 就被标记为“分歧 token”。统计这样的 token 数量后，两条路线都可以使用这个计数：DTClin 把计数直接转换成低分（计数越多，置信度越低），DTCprod 则用计数对轨迹的平均 token 概率做重校准。这个框架的几个关键设计意如图 1 所示：生成过程完全不受影响，辅助模型可以是任意规模的公开模型，不需要任何训练或微调。

在实验上，论文首先在白盒环境中对 8 个模型（Qwen2.5、Qwen3、Gemma3 三个家族）和 4 个数学基准（MATH-500、AMC23、AIME24、AIME25）进行验证。它与三类基线对比：标准全序列置信度（CNSL、Cmean、熵置信度）、改进过的 token 选择方法（BaseCal、UQACattn、UQACmean）、以及口头化置信度（Verb. Conf、Verb. TopK、Verb. PD）。结果显示，仅用计数的 DTClin 在 ECE 上平均可达 13.0%，而标准方法为 32.7%–42.4%；即使在 verbalized 基线之上叠加 DTC，也能大幅降低 ECE。同时 DTC 的 AUROC 基本保持或略有改善，说明它主要改善的是“分数与真实准确率之间的匹配”，而不是固有的判别力。

黑盒实验在 DeepSeek-V3.2 上展开，三种 Verbalized 方法先用提示模板生成置信度，然后用 DTC 做后处理。这里 DTC 的贡献更为明显：不仅将 ECE 从 32.1%–40.2% 压到 13.7%–16.3%，还规避了 Verbalized 方法带来的准确率下降（从 57.5 降到 44.9–51.5）。作者认为这是因为 DTC 依赖外部辅助模型而不是让生成器自我报告信心，因此不会干扰原始解码行为。

论文还做了敏感性分析，表明 DTC 对于阈值 θ 和辅助模型大小具有鲁棒性：最优 θ 大致落在 0.25–0.55，不同辅助模型大小都能获得接近最优的 ECE。这表明 DTC 是一个易于落地的方法，不需要精细超参搜索。

最后，作者总结认为 DTC 的价值在于提供了一个“概率之外”的置信度来源：两个模型在推理链上的分歧计数。该方法简单、通用，并可以融入到白盒和黑盒两种部署形态中。论文同时也指出，DTC 的 AUROC 提升有限，说明它在排序能力上还有改进空间，且方法目前聚焦数学推理域。总的来说，本文以“计数”代替“概率值”的视角，为推理不确定性量化提供了新的思路，并且具备很强的实用性和可复现性。
