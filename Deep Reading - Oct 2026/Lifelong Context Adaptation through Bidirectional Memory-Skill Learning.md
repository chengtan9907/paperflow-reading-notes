# Lifelong Context Adaptation through Bidirectional Memory-Skill Learning

## 一句话总结

论文提出 MEMCRYST，一个在冻结语言模型上通过“记忆—技能”双向学习实现终身上下文适应的框架：记忆中的重复经验支持技能创建与修订，技能引导的交互又产生新记忆，任务结果则调整被检索记录的未来检索影响力而不改写其内容。

## 摘要

> 论文关注终身 LLM 智能体在上下文窗口有限、交互历史不断扩张条件下的适应问题。外部记忆让过去经验可被检索，但检索到的记录通常只提供事实或证据，智能体仍需自行推断如何完成新任务；技能提供可复用流程，却可能遗漏应用所需的任务特定事实与约束。MEMCRYST 让记忆与技能双向耦合：记忆中反复出现的经验支持技能创建和修订，技能引导的交互又为后续技能修订提供新记忆；检索出的事实与学到的技能共同构成智能体上下文。任务结果用于调整“实际被服务过的记录”在未来检索中的影响力，但不重写记录内容，从而在保留证据原貌的同时实现检索策略的在线适应。摘要可见部分称该框架跨十个设置进行评估，涵盖具身控制与长文档等场景；摘要末尾在 MUSE-AutoSkill 处截断。

Q1: 这篇论文试图解决什么问题？

论文试图解决的是终身 LLM 智能体在“上下文有界、历史无界、模型冻结”三重约束下的经验积累与复用问题。具体而言：（1）智能体面对持续到来的任务流，每次决策只能使用有限的上下文窗口，不能把全部交互历史塞进提示词；（2）基础语言模型不更新参数，适应必须发生在外部的记忆、技能和检索策略上；（3）记忆检索能提供过去的事实与证据，但检索到的记录通常不直接告诉智能体“下一步该怎么做”，智能体仍需从零推断任务程序；（4）技能能提供可复用流程，却往往省略应用时所需的任务特定事实、实体绑定和约束条件。由此产生一个双向耦合难题：检索到的记忆与技能会塑造智能体的行为，行为产生的新经验又改变未来可检索的记忆与技能；如果只优化其中一侧，系统会在“有证据但不会做”和“有流程但缺事实”之间摇摆。论文进一步把问题落在“在线学习外部状态”上：不是离线建库，而是在任务流中持续决定存什么、检索什么、如何修订技能、如何把结果归因到实际服务过的记录。这里的隐含假设是任务流中存在可复用的重复结构，任务结果可作为信用信号，且冻结模型具备从上下文中归纳和使用技能的能力；若任务彼此独立、结果信号稀疏或记忆记录本身有噪声，这些假设会承压。评价设计也因此不能只看单任务准确率，而要看跨任务序列上的累积收益、检索策略是否随结果改善、技能是否随重复经验修订而不漂移，以及有界上下文下记忆与技能如何取舍。

Q2: 有哪些相关研究？

相关工作可沿四条线组织。第一，外部记忆增强的 LLM 智能体：一类工作把交互记录、事实或压缩笔记写入外部记忆，再按相似度检索供后续任务使用，片段提及 Xu et al., 2025、Fang et al., 2026a、Liu et al., 2026 等；这类方法的核心优势是保留证据、支持长历史，但检索到的内容仍需要智能体自行解释为行动程序，且记忆写入与检索策略往往分离。第二，技能或可复用程序学习：一类工作从经验中抽取可复用过程，指导后续相似任务，片段提及 Wang et al., 2024a、Zheng et al., 2025a、Ni et al., 2026 等；技能压缩了决策结构，但可能丢失任务特定事实、实体绑定和约束，导致“会流程但不会落地”。第三，记忆与技能结合的系统：摘要明确提到 MUSE-AutoSkill 围绕演化技能组织经验，MSCE 则用存储的证据和反馈指导技能发展；这些是最接近 MEMCRYST 的路线，差异在于 MEMCRYST 强调双向闭环、冻结语言模型、结果驱动的检索影响力更新，以及技能修订的独立审计与替换。第四，经验反思与检索增强的智能体基线：片段中出现 ReAct、ExpeL 和 ALFWorld，说明论文把“推理—行动”式智能体、经验反思式学习和具身文本环境作为对照与评测背景。总体看，论文把既有工作概括为“记忆提供证据但缺程序、技能提供程序但缺事实”，并主张二者不是简单拼接，而是通过重复经验与结果反馈互相生成、互相约束；其新颖点主要在外部状态的在线维护机制，而非新的基础模型或新的监督信号。

Q3: 论文如何解决这个问题？

MEMCRYST 的技术路线可以概括为“外部状态承载学习，冻结模型负责推理与生成”。从摘要与检索片段可辨识出以下组件：（1）情节记忆库：存储任务交互、事实、反馈或改进记录，记录内容保持相对稳定，作为可追溯的证据来源；（2）技能库：存储从重复经验中归纳出的可复用程序或决策结构，技能与触发它的经验簇相关联；（3）上下文组装器：针对当前任务，从记忆库检索事实、从技能库选择技能，二者共同构成有界上下文，分别补足“事实约束”和“行动程序”；（4）检索影响力权重：每条被检索并实际服务过的记录带有可更新的影响力，任务结果用于上调或下调其未来被检索的倾向，但不改写记录内容，从而避免摘要式重写造成的信息损失与污染；（5）技能创建与修订回路：反复出现的经验被聚类后，用于合成候选技能或候选修订；候选会在新上下文中接受审计，通过后才替换旧技能，片段中出现 Replace(s⋆, sCj, Cj) 与状态量 u 的伪代码痕迹，但 u 的具体语义在抽取文本中无法确认；（6）技能引导的交互再写入记忆：使用技能完成任务后产生的新情节与结果，又成为后续技能修订和检索权重更新的材料，形成“记忆→技能→交互→新记忆”的闭环。检索侧片段还显示一种按实体、作用域和相似度筛选的逻辑：优先取同实体同作用域且相似度达标的记录，否则按家族子组返回至少三个成员并丢弃其余；这暗示系统在检索时不仅追求相似，还试图保持证据的覆盖与多样性。整体设计把“学习”放在外部状态而非参数上：技能压缩程序，记忆保留事实，权重表达经验效用，审计控制技能质量。其合理推断的优点是无需微调、可解释、可回滚；潜在代价是记忆增长、检索延迟、审计成本和信用分配的噪声。

Q5: 发现了什么实验现象？

从可见片段看，最显著的现象是完整系统与基线之间存在数量级差距：MEMCRYST 在 955 个任务上报告 709 个成功（74.24%），而 ReAct 为 72/955（7.54%）、MSCE 为 157/957（16.41%）。这一差距不能简单解释为“多了记忆”，因为记忆型基线 MSCE 仍远低于完整系统，说明关键可能在记忆、技能与结果驱动检索三者的耦合，而非单一存储。片段中 MEM 与 CRYST 的对比暗示两侧各有贡献：MEM 保持事实返回，CRYST 在多个基准上提升成功率，完整 MEMCRYST 进一步组合二者；这支持“事实证据”和“可复用程序”互补的解释。第二个现象是 collection 与 serving 的分离：ExpeL 在 serving path 注入收集到的 insights 时得 44.8%，而 collection-only 的设置表现不同，说明“把经验收集起来”不等于“在决策时用得上”，服务时的检索与注入策略是关键变量。第三个现象是技能修订需要审计：伪代码显示候选修订要在新上下文中审计，接受后才替换旧技能并重置状态量；合理推断这是为了防止技能在自我确认的上下文中漂移，但片段没有给出接受率、修订收益或审计失败案例。第四个值得注意的张力是“不可回答”列：若 48.0 确实对应不可回答子集，则系统在高任务成功率之外仍可能在“该拒答时拒答”上明显不足；若该列对应其他指标，则需重新解释。片段没有展示明确的负结果、失败案例或 scaling trend，因此不能声称系统在所有任务类型上都单调受益；更稳妥的判断是：在存在重复结构且结果可归因的任务流中，双向闭环可能带来大幅收益，但在非重复任务、稀疏奖励或记忆噪声场景下可能退化。

Q6: 有什么可以进一步探索的点？

可进一步探索的方向包括：（1）更精细的信用分配：当前做法似乎只调整实际被服务记录的未来检索影响力，可引入反事实检索、Shapley 式归因或上下文 bandit，将任务结果更准确地分配到“哪条记忆/哪个技能真正起作用”，并处理延迟奖励与稀疏奖励。（2）检索策略的持续学习：把实体/作用域/相似度阈值、家族子组的最小成员数、记忆与技能的配额变成可学习策略，研究探索—利用平衡与记忆老化。（3）技能表示与验证：为技能增加前置条件、后置条件、适用域、失败模式和不确定性，支持技能组合、层级调用与自动验证；独立审计可扩展为多审计器投票或执行级验证。（4）理论分析：把双向闭环建模为动态系统，分析记忆权重更新与技能替换的稳定性、收敛性、误差传播和上下文预算约束下的最优分配。（5）评测设计：构建非平稳、延迟反馈、对抗性记忆、跨域迁移和终身序列基准，报告累积 regret、遗忘、技能漂移和拒答质量，而不仅是最终成功率。（6）安全与治理：研究记忆投毒、隐私泄露、不可学习请求、审计追踪和可删除性；外部记忆越强，治理需求越高。（7）效率：记忆去重、压缩、分层索引、检索缓存和审计预算控制，决定系统能否在真实长周期中运行。（8）跨领域扩展：把“事实记忆 + 程序技能”迁移到多模态智能体、工具使用、多智能体共享记忆，以及 AI for science 中的实验协议与实验记录管理。
