# Global Optimization and Inference-Time Region Grafting for Agentic Workflows

> ★★★★☆ 推荐阅读 · 模型 openai-compatible/deepseek-v4-flash

🏷 关键词：agentic workflow · inference-time adaptation · workflow optimization · region grafting

## 一句话总结

GRAFT 是一种无需训练参数的推理时区域嫁接（region grafting）方法，它在保留全局优化工作流的同时，仅针对每个输入局部替换有问题的区域，利用无标签执行质量信号实现实例级自适应，在五个基准上平均比最强先验工作流优化方法 MaAS 提升 3.85 分。

## 摘要

> Recent advances in agentic workflow optimization automate workflow design through task-specific workflow search or input-conditioned architecture selection. However, they determine the workflow before execution and cannot adapt failed workflow regions using execution-time label-free quality signals. Naively enabling such inference-time adaptation through whole-workflow re-optimization would be computationally prohibitive. To tackle this challenge, we introduce GRAFT, which preserves a globally optimized workflow while locally replacing only selected regions for each input. Without parameter training, GRAFT evaluates region-level alternatives using label-free execution-quality signals and accepts only replacements that improve local quality while preserving workflow-level consistency, thereby enabling instance-wise adaptation without whole-workflow re-optimization. GRAFT applies without modification across a range of tasks spanning mathematical reasoning, code generation, and multi-hop and knowledge-intensive question answering. Under matched optimizer and executor settings, it improves over the strongest prior workflow-optimization method, MaAS, by 3.85 points on average. Replacing only the executor with a stronger model yields further gains without re-optimizing the global workflow. This suggests that an optimized workflow is not merely a static optimization artifact, but an adaptable execution policy that can evolve with inference-time feedback and stronger executors.

Q1: 这篇论文试图解决什么问题？

这篇论文针对的是智能体工作流优化中的一个关键缺口：现有工作流优化方法虽然在离线阶段能够搜索或学习出较优的工作流结构，但它们在执行之前就固定了整个工作流，无法在推理过程中根据实际执行情况动态调整。具体而言，主要问题可以拆解为三点：
1. 静态工作流的局限：无论是基于任务特定搜索（如 AFlow）还是输入条件化架构选择（如 MaAS）的方法，都假设工作流一旦确定就可以应对所有输入。但真实场景中不同输入可能需要不同的推理路径、不同的工具组合或不同的子任务分配，静态工作流在面对失败区域时缺乏自愈能力。
2. 推理时自适应的难度：如果希望通过执行时的质量信号来改进工作流，最直接的想法是每当发现失败就重新优化整个工作流。但 agentic workflow 通常包含多个区域、多个 agent 和复杂的依赖关系，整体重新优化需要大量额外的 LLM 调用和搜索步骤，计算开销在推理阶段难以承受。
3. 局部修改与全局一致性的权衡：只修改失败区域看似可行，但局部替换可能破坏工作流其他部分的信息传递、状态一致性和任务衔接，导致整体性能反而下降。因此，需要设计一种机制，在允许局部调整的同时，保证工作流级的一致性。
此外，论文还指出了一个深层挑战：在没有外部反馈的情况下，让 LLM 评估并修正自己的推理可能不可靠，甚至会降低性能。这意味着推理时自适应不能简单地依赖 LLM 的自我反思，而需要更结构化的质量信号和更严格的接受准则。另外，多智能体系统中还存在区域间干扰问题，即一个区域的失败可能源于上游区域的问题，或者下游区域的行为会掩盖上游区域的真正缺陷。这些因素共同构成了论文要解决的核心问题。

根据检索到的相关工作和论文摘要，本文涉及以下几个研究脉络：
1. 自动智能体工作流生成（Automatic Agentic Workflow Generation）：已有研究探索自动优化基于 LLM 的智能体结构和工作流组件。例如 Hu, Lu, and Clune (2025) 使用元智能体（meta-agent）迭代地生成并改进工作流，这属于离线优化路线，代表方法包括 AFlow 和 MaAS。这些方法通过搜索或输入条件化来优化工作流，但都是在执行前确定结构。
2. 动态工作流与推理时调整：Niu et al. (2025) 提出了在执行过程中通过调整子任务分配和智能体角色来改进工作流的方法。这类方法虽然开始关注执行时动态，但通常涉及全局性的调整，且可能依赖特定的反馈机制。
3. 超网络与动态工作流（Supernets and Dynamic Workflow）：研究领域中有工作探索针对不同查询配置不同工作流路径，类似于超网络根据输入动态选择模块。GRAFT 与之相关但侧重点不同：它使用全局优化好的工作流作为种子工作流，并在推理时为每个查询配置不同的局部工作流，而不是从头构建动态结构。
4. 推理时自适应与标签无关质量信号：更广义的研究包括在推理阶段利用无标签信号来优化生成结果，例如置信度校准、自洽性检查或外部工具反馈。GRAFT 属于这一类，但特别强调区域级（region-level）的嫁接和接受准则。
5. 多智能体系统中的失败分析：论文提到失败分析识别了多智能体系统中的区域间干扰问题，这与多智能体协作、错误传播和可解释性研究相关。GRAFT 的局部嫁接机制可视为对这类失败模式的一种直接回应。
整体来看，本文的工作处于离线工作流优化和在线推理时自适应的交汇点，既不同于完全离线搜索，也不同于全局在线重新规划，而是提出了一个细粒度的局部调整范式。

Q3: 论文如何解决这个问题？

GRAFT 的具体方法细节在摘要和检索片段中并未完全展开，但根据摘要和引言片段可以合理推断其核心流程如下：
1. 种子工作流：GRAFT 以一个全局优化好的工作流（例如由 AFlow 或 MaAS 生成的流程）作为起点。这个工作流可以视为离线阶段寻找到的全局最优或近优结构。
2. 区域划分：整个工作流被划分为多个区域（region），每个区域对应一个可独立替换的子任务、agent 角色或推理步骤。区域划分的粒度决定了局部调整的灵活性和计算开销。
3. 候选区域生成：在推理时，对于当前输入，GRAFT 可能会针对每个区域生成多个可选的替代实现（例如不同的 prompt 策略、不同的 agent 角色、不同的工具调用序列），或者根据执行状态动态选择候选。这一步的具体机制论文没有在摘要中说明，可能是通过 LLM 采样或预定义候选池实现，属于合理推断。
4. 标签无关质量信号评估：GRAFT 不使用人工标注或外部真值，而是利用执行过程中可获得的启发式信号（如中间步骤的自洽性、逻辑一致性、工具返回状态、输出分布熵等）来评估区域级替代方案的质量。引言中提到“没有外部反馈时，让 LLM 评估和修正自己的推理可能不可靠”，因此 GRAFT 可能采用了比简单自我反思更稳健的信号聚合方式。
5. 接受准则：GRAFT 只接受那些能够提升局部质量并且不破坏工作流级一致性的替换。这意味着它有一个双重条件：局部质量必须改善，同时整体工作流的信息流、任务衔接和最终输出格式必须保持不变。被拒绝的替换会被回滚，保留原区域。
6. 推理时自适应：通过上述步骤，GRAFT 为每个输入实例独立地配置工作流，实现实例级（instance-wise）的自适应。整个过程无需训练参数，不需要对整个工作流进行重新优化，因此计算开销远低于全局重优化。
7. 执行器替换的灵活性：GRAFT 还可以在保持全局工作流不变的情况下，将执行器（executor，即执行子任务的 LLM）替换为更强的模型，而无需重新优化工作流，说明该方法对执行器变化具有稳健性。
总体而言，GRAFT 的核心创新在于将全局优化与局部嫁接解耦，通过区域级的筛选机制把推理时自适应控制在可接受的计算开销内，同时通过一致性约束避免局部修改带来的副作用。

根据目前可获取的证据，论文报告了以下主要实验现象：
1. 局部嫁接优于全局静态工作流：在相同的优化器和执行器配置下，GRAFT 在五个基准上的平均分达到 87.44，比最强的先前方法 MaAS 高出 3.85 分。这说明推理时对问题区域进行局部替换确实能带来一致的性能提升。
2. 执行器升级无需重新优化：仅将执行器替换为更强的模型，GRAFT 也能获得进一步增益，而无需重新优化全局工作流。这是一个反直觉的结果——传统观点会认为更换执行器后工作流需要重新适配，但 GRAFT 表明优化后的工作流结构对执行器变化具有鲁棒性，可以自然地从更强的执行能力中获益。
3. 标签无关信号的有效性：由于 GRAFT 不依赖外部真值标签，而是使用执行时的质量信号，这一结果也间接验证了在推理阶段利用启发式信号进行区域筛选是可行的。
4. 区域间干扰的存在与缓解：引言中提到的失败分析识别了多智能体系统中的区域间干扰问题，而 GRAFT 的接受准则（要求保持工作流级一致性）可能正是对这种干扰的回应。推测实验观察表明，不加一致性约束的局部替换容易导致整体性能下降，而 GRAFT 的约束条件能够抑制这类负效应（此点属于基于问题动机的合理推断）。
5. 自我评估的不可靠性：引言提到没有外部反馈时让 LLM 评估和修正自身推理可能不可靠并降低性能，这暗示实验中可能观察到简单的自我反思式自适应会带来负面效果，而 GRAFT 的结构化评估与区域嫁接方式避免了这一陷阱。

7. 可解释性与失败分析：区域嫁接提供了一种天然的调试接口——通过观察哪些区域被替换以及替换的原因，可以诊断工作流的薄弱环节。未来可以发展可视化和归因工具。

Q7: 总结一下论文的主要内容

这篇论文提出并验证了 GRAFT，一种用于智能体工作流的推理时区域嫁接方法。论文的核心论证起点是：现有的智能体工作流优化方法，如基于任务特定搜索的 AFlow 和输入条件化架构选择的 MaAS，虽然能在离线阶段找到较优的工作流设计，但它们本质上是静态的——工作流在执行前被确定，之后无法利用执行过程中产生的无标签质量信号来调整失败区域。这种静态性限制了工作流在真实场景中的泛化能力，因为不同输入可能需要不同的推理路径、子任务分配或工具组合。
直接让工作流在推理时自适应是困难的：最朴素的重优化方案需要对整个工作流进行重新搜索，这在计算上不可行。同时，仅依赖 LLM 自我反思也不可靠，没有外部反馈时，LLM 评估和修正自身推理可能会降低性能。此外，多智能体系统中的区域间干扰使得局部修改可能带来不可预知的副作用。
针对这些挑战，GRAFT 提出了一个优雅的思路：保留全局优化好的工作流，将其作为种子，然后在推理时针对每个输入局部地替换有问题的区域。整个过程无需训练参数。具体而言，GRAFT 利用执行时收集的无标签质量信号来评估区域级的替代方案，并且只接受那些既能提升局部质量又能保持工作流级一致性的替换。这个接受准则非常关键，它既保证了局部改进的有效性，又避免了局部修改对全局信息流和任务衔接的破坏。通过这种方式，GRAFT 实现了实例级的自适应，而无需对整个工作流进行重新优化。
在方法验证方面，论文设计了系统的实验。实验覆盖了数学推理、代码生成、多跳问答和知识密集型问答五类基准任务。在匹配优化器和执行器的公平设置下，GRAFT 的平均得分达到 87.44，比最强的先前工作流优化方法 MaAS 高 3.85 分。这直接回答了 RQ1：推理时区域嫁接确实能改进离线优化的工作流。RQ2 则关注收益的来源，推测通过消融实验验证了收益来自局部嫁接机制本身而非额外计算量或自我修正。更进一步的实验显示，仅将执行器替换为更强的模型，无需重新优化全局工作流，也能获得额外性能提升。这一结果具有很强的启示意义：优化后的工作流并非一个僵化的静态产物，而是一个可以随推理时反馈和更强执行器而演化的可适应执行策略。
论文还分析了失败模式，识别出多智能体系统中的区域间干扰问题，这为区域嫁接和一致性约束提供了动机。整体来看，GRAFT 的工作可以概括为三个主线：一是问题主线，指出静态工作流优化的局限和推理时自适应的挑战；二是技术主线，提出全局优化与局部嫁接解耦、无标签信号评估、一致性约束接受准则；三是实验主线，通过多任务、多基线和执行器替换实验验证方法的有效性和泛化性。论文的定位处于离线工作流优化和在线动态工作流之间，填补了“全局优化工作流如何在推理时低成本适应”这一空白。
